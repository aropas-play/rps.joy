Aropas Introduction

Learn more about modern active Rock-Paper-Scissors (Aropas) AI technology and gameplay.

1. Overview & Concept

Aropas brings active physical interaction to the classic Rock-Paper-Scissors game by using real-time AI computer vision models. Players can participate using hand gestures or full body postures directly in front of their camera.

2. Active Hand Gesture Recognition

Using on-device machine learning, Aropas recognizes hand gestures in real-time without latency. The AI analyzes finger positions to accurately match Rock, Paper, or Scissors inputs without sending any video data to cloud servers.

→ Learn More about AI Gesture Detection

3. Body Posture Gameplay

Take the active gaming experience to full-body movement! Aropas supports full-body posture tracking where movements map into game actions, encouraging physical activity and engaging interactive play.
